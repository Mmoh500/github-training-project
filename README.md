# Simple E-Commerce Logic (Dart Training)

This project is a clean, command-line implementation of a shopping cart system built with **Dart**. It was developed as part of a technical training to master Git workflow, branching strategies, and GitHub collaboration tools.

## Overview
The application simulates a basic retail flow, including:
* **Item Management:** Define products with specific attributes.
* **Cart Logic:** Adding items, calculating totals, and managing quantities.
* **Checkout Process:** A structured flow from selection to final payment logic.

## Tech Stack
* **Language:** Dart
* **Framework:** Flutter (Core Logic)
* **Version Control:** Git & GitHub

## Project Structure
* `bin/`: Contains the main entry point for the CLI application.
* `lib/`: Core logic and library files (e.g., `Cart.dart`, `Item.dart`).
* `test/`: Unit tests to ensure logic reliability.

## How to Run
1.  Ensure you have the Dart SDK installed.
2.  Clone the repository:
    ```bash
    git clone [https://github.com/Mmoh500/github-training-project.git](https://github.com/Mmoh500/github-training-project.git)
    ```
3.  Navigate to the directory and run:
    ```bash
    dart bin/main.dart
    ```

## Key Git Operations Applied
* Feature branching (`feature/design-update`).
* Issue tracking and resolution on GitHub.
* Successful merging and PR (Pull Request) management.
